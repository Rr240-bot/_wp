### JavaScript練習

## 解題思路

# 1.滿額折價計算機（if / function）
1.建立一個名為 calculatePrice 的功能（函式），需要傳入一個參數 originalPrice（原始金額）。

2.在函式內部，我們需要「由高到低」去判斷金額區間：

先看有沒有滿 2000，有就打 8 折（乘以 0.8）。

3.沒滿 2000 的話，再看有沒有滿 1000，有就打 9 折（乘以 0.9）。

如果以上都沒有，代表是一般金額，直接回傳原價。

 # 2.終極密碼猜數字（while / if）
1.設定一個固定答案 answer = 42。

2.因為在純 JavaScript 環境（如 Node.js）中連續讓使用者輸入比較麻煩，我們用一個陣列 playerGuesses 來「模擬」玩家依序輸入的數字。

3.使用 while 迴圈。只要索引值（index）還沒超出陣列範圍，就一直重複執行。

4.每次迴圈取出一個數字，用 if 比較：太大了、太小了、還是猜中了。

5.如果猜中，印出訊息並用 break 強制跳出迴圈。
# 3.九九乘法表列印（for 雙層迴圈）
1.外層 for 迴圈代表「被乘數 $i$」，從 1 跑到 9。

2.當 $i$ 是 1 的時候，內層 for 迴圈「乘數 $j$」要從 1 跑到 9，把 $1 \times 1$ 到 $1 \times 9$ 算完。

3.為了讓同一排的數字印在一起，我們先宣告一個空字串 row，把內層算好的結果一個一個「貼」上去（用 +=），並加上 \t（定位鍵，用來對齊欄位）。

4.內層迴圈跑完一輪（代表某一排算完了），就用 console.log(row) 把那一排印出來。
# 4.陣列數字大風吹（for / array）
1.假設陣列裡的第一個數字（索引值 0）同時是目前看到的「最大值」與「最小值」。

2.用 for 迴圈從第二個數字（索引值 1）開始，一關一關往下比對。

3.如果發現目前的數字比 max 還大，就把 max 換成它；如果比 min 還小，就把 min 換成它。

4.最後用一個物件的形式把這兩個結果包起來回傳。
# 5購物車總金額計算（for / object / array）
1.購物車是一個陣列 [ ]，裡面放了多個商品物件 { }。

2.我們需要一個變數 total 先設定為 0，用來累積總金額。

3.用 for 迴圈依序讀取陣列裡的每一個商品物件。

4.透過「物件屬性存取」的方式，抓出商品的價格（.price）和數量（.quantity），兩者相乘就是該商品的個別總價。

5.把個別總價累加到 total 中。
# 6聯絡人通訊錄（object / function）
1.建立一個大物件 phoneBook。

2.內部宣告一個屬性 contacts: []（空陣列），用來存放未來的聯絡人。

3.物件裡面的函式我們稱為「方法（Method）」。

4.addContact 負責接收名字和電話，包成一個小物件推入（push）陣列中。在方法內要存取同一個物件的屬性，必須使用 this.contacts。

5.findContact 則是用迴圈去陣列裡找名字。如果名字對上了，就回傳電話；如果整圈跑完都沒找到，就回傳提示文字。
# 7.學生資料過濾器（array / if / function）
1.這個功能的目標是「篩選（Filter）」。

2.在函式內先準備一個全新的空陣列 passed，準備用來放合格的人。

3.用迴圈把原本的學生陣列巡一遍。

4.每次巡到的時候，用 if 檢查該學生的分數（.score）有沒有大於等於 60。

5.如果有，就把整個學生資料物件 push 進入 passed 陣列。

6.最後把這個裝滿合格者資料的新陣列回傳。
# 8.JSON 格式 API 資料解析（JSON / array / for）
1.當我們從網路（API）抓取資料時，拿到的通常是純文字字串（JSON 格式）。

2.在 JavaScript 裡，純字串是沒辦法直接用 .email 或 [0] 去抓資料的。

3.所以第一步，必須使用 JSON.parse(jsonString) 把純文字還原成 JavaScript 認得的真實「陣列與物件」。

4.轉換成功後，它就是一個普通的陣列了，接下來就可以用 for 迴圈遍歷，把每個物件裡的 email 印出來。
# 9.待辦事項序列化（JSON / object）
1.這題跟上一題相反。這次是我們網頁上有一個活生生的 JavaScript 物件 todoList。

2.如果我們想把這個資料傳給後端儲存，或是存進瀏覽器的 localStorage，我們必須把它轉成純文字。

3.這個將物件變成 JSON 文字的過程叫做「序列化（Serialization）」。

4.我們使用 JSON.stringify(todoList) 來達成，它會回傳一串符合 JSON 標準的字串。
# 10.綜合大魔王：簡易圖書管理系統（全觀念整合）
1.建立 librarySystem 物件，內建 books 陣列當作資料庫。

2.新增書籍（addBook）：傳入書名與作者，預設書籍狀態 isAvailable（是否可借）為 true，然後推入陣列。

3.借閱書籍（borrowBook）：

用 for 迴圈根據書名找書。

如果找到了（第一層 if），再檢查 isAvailable 是不是 true（第二層 if）。

如果可以借，就把狀態改成 false，並回傳成功訊息。如果已經被借走，回傳被借走的訊息。

如果迴圈跑完都沒這本書，回傳找不到。

4.資料匯出（exportData）：直接把 this.books 陣列透過 JSON.stringify 變成文字回傳。
