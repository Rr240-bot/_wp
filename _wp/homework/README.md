## 1. 標題 (Headings)

在文字前面加上 `#` 號和**一個空格**，就能定義標題。`#` 越多，字體越小（最多支援到 6 層標題）。

```markdown
# 一級標題（最大）
## 二級標題
### 三級標題
#### 四級標題

```

---

## 2. 文字樣式 (Emphasis)

用來強調、加粗或劃掉特定的文字。

* **粗體**：在文字前後各包 2 個星號 ``
* *斜體*：在文字前後各包 1 個星號 `*`
* ~~刪除線~~：在文字前後各包 2 個波浪號 `~~`

```markdown
這是正常的文字。
這是 **粗體文字**，用來抓眼球。
這是 *斜體文字*。
這是 ~~寫錯被劃掉的文字~~。

```

## 3. 清單 (Lists)

清單分為「無序」與「有序」兩種，記得符號後面都要加**一個空格**。

### 無序清單

使用 `-` 或 `*` 作為開頭。

```markdown
- 蘋果
- 香蕉
- 葡萄

```

### 有序清單

直接使用數字加上英文句點 `.`。

```markdown
1. 第一步驟
2. 第二步驟
3. 第三步驟

```

> **💡 小技巧**：在清單項目按下 `Tab` 鍵，就可以縮進，做出「子清單」喔！

## 4. 連結與圖片 (Links & Images)

這兩個語法長得很像，非常好記。秘訣是：**「圖片只比連結多了一個驚嘆號 `!`」**。

### 插入連結

語法：`[顯示的文字](網址)`

```markdown
歡迎造訪 [Google 首頁](https://www.google.com)。

```

### 插入圖片

語法：`![圖片替代文字](圖片網址)`

```markdown
![可愛的貓咪](https://example.com/cat.jpg)

```

## 5. 區塊引用 (Blockquotes)

如果你想引用別人說的話，或者寫一段特別突出的筆記，可以在開頭加上大於符號 `>`。

```markdown
> 這是引用區塊。
> 「學而不思則罔，思而不學則殆。」—— 孔子

```

顯現出來的效果就會像上面那樣，左邊多一條垂直線。

## 6. 程式碼 (Code)

這是工程師和筆記控最愛的功能！

### 行內程式碼

如果只想在句子中穿插一個小標籤或變數，前後用 1 個反單引號 ```（鍵盤 Tab 鍵上方那個按鈕）包起來。

```markdown
請在終端機輸入 `npm install` 來安裝套件。

```

### 多行程式碼區塊

如果要貼上一整段程式碼，前後用 3 個反單引號 ````` 包起來。你還可以在開頭指定程式語言（例如 `javascript`、`html`），這樣程式碼就會有漂亮的顏色高亮（Highlight）！

```markdown
```javascript
function greet(name) {
    console.log("Hello, " + name);
}
greet("Alex");

```

```

## 7. 表格 (Tables)
表格是用直線 `|` 來分隔欄位，並用虛線 `-` 來區隔標題列與內容。

```markdown
| 姓名 | 年齡 | 職業 |
| --- | --- | --- |
| 小明 | 25 | 工程師 |
| 美美 | 22 | 設計師 |

```

顯示出來的效果會非常整齊：

| 姓名 | 年齡 | 職業 |
| --- | --- | --- |
| 小明 | 25 | 工程師 |
| 美美 | 22 | 設計師 |

## 實戰小練習 ✍️

你可以現在複製貼上這段文字到支援 Markdown 的編輯器裡，試著把其中的語法補齊：

```markdown
1. 把這行變成三級標題： 我是標題

2. 把「重要」變粗體： 這件事情非常 重要 。

3. 做一個珍奶微糖微冰的無序清單：
(提示：用減號)

4. 試著把 `code` 寫成行內程式碼。

```
